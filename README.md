# React Image Gallery

A simple and responsive image gallery built with **React.js**, **Tailwind CSS**, and the **Picsum Photos API**.

## Features

* 📸 Dynamic images fetched using Axios
* 🔄 Pagination with Previous and Next buttons
* 🖼️ Responsive masonry-style gallery
* ✨ Smooth image hover effects
* 🔗 Click images to view the original source
* 📱 Responsive layout for different screen sizes
* ⚡ Next-page image preloading for faster navigation

## Technologies Used

* React.js
* Tailwind CSS
* Axios
* Picsum Photos API
* Vite

## Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project folder:

```bash
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in your terminal.
